# Supporto Vencord Italiano

Questo repository gestisce la build italiana di Vencord: traduzione, localizzazione dei plugin, RealVoiceTTS e updater.

## Dove segnalare

Usa le GitHub Issues di questo repository per:

- errori della traduzione italiana;
- testo non tradotto o tradotto male;
- regressioni specifiche della build italiana;
- problemi di RealVoiceTTS;
- problemi dell'aggiornamento automatico che punta a Vencord Italiano.

Per problemi dell'installer Windows usa invece:

https://github.com/davidev3p0/Vencord-Italiano-Installer/issues

Per problemi generali di Vencord non causati dalla build italiana, consulta il supporto upstream.

## Dati sensibili

Non pubblicare token Discord, password, cookie, credenziali, email private o altri dati sensibili.
