RealVoiceTTS - Google + Ctrl/Clic

MODIFICHE:
- Preferisce automaticamente una voce Google italiana, se Discord/Chromium la espone.
- Se la voce Google italiana non è disponibile, usa la migliore voce italiana disponibile.
- Ctrl + clic sinistro è ora la modalità predefinita per leggere un messaggio.
- La migrazione alle nuove impostazioni avviene una sola volta: dopo potrai cambiare voce/modalità senza che il plugin le sovrascriva a ogni avvio.

INSTALLAZIONE:
1) Chiudi Discord.
2) Estrai questo ZIP dentro:
   C:\Users\Davide\Documents\Vencord
   sovrascrivendo il file esistente.
3) Da PowerShell nella cartella Vencord:
   pnpm build
4) Se la build riesce:
   git add .
   git commit -m "RealVoiceTTS Google e Ctrl click"
5) Esegui:
   pnpm inject
6) Seleziona Discord Stable e riapri Discord.

NOTA GOOGLE:
Il plugin usa l'API SpeechSynthesis di Chromium/Discord.
Una voce Google può essere usata soltanto se compare tra le voci esposte dal client.
Se non compare, il plugin mostra un avviso e usa automaticamente la migliore voce italiana disponibile.
