# Changelog Vencord Italiano

- localizzazione italiana dell'interfaccia Vencord;
- localizzazione dei nomi visualizzati dei plugin;
- helper di traduzione che mantengono invariati ID e chiavi tecniche;
- RealVoiceTTS;
- attivazione lettura con Ctrl + clic;
- selezione delle voci disponibili tramite Discord/Chromium;
- build standalone collegata a `davidev3p0/Vencord-Italiano`;
- aggiornamenti automatici testati end-to-end;
- workflow di release pubblica;
- repository installer Windows dedicato.
